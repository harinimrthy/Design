# DigitalHub – UI/UX Ecommerce Learning Platform

## Project Overview
DigitalHub is a modern ecommerce learning platform designed to help students access premium learning resources, tutorials, notes, AI tools, and career guidance through an easy-to-use interface.

---

## Features
- Onboarding Screens
- Home Page
- Categories Page
- Product Detail Page
- Login & Signup
- User Dashboard
- Mobile Responsive Design
- Course Progress Tracking
- Wishlist & Download Resources
